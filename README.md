# NBWebX Dental Template

Template reutilizável para clínicas odontológicas.

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Vercel
- Supabase (próxima etapa)

## Rodar
```bash
npm install
npm run dev
```

Acesse:
- `/` site público
- `/admin` dashboard
- `/admin/identidade` editor de branding

## Estado atual
O editor de identidade salva as configurações em `localStorage` para prototipação. Na próxima etapa, substitua pelo Supabase para persistência multi-clínica e uploads de logo/hero em Storage.
